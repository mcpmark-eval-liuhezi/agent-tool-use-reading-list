# agent-tool-use-reading-list

Reading group tracker for papers on **tool use / function calling in large language model agents**.

## What this is

Instead of leaving the reading list in a stale doc, this repository is the tracker for our reading group. Each paper gets its own child issue (attached as a sub-issue of the parent reading-list issue), where we keep notes, discussion points, and open questions before and after each session.

## Structure

- **Parent issue:** "Reading list: tool use in LLM agents" — introduces the reading group and the selection criteria.
- **Child issues (sub-issues):** one per paper, titled with the paper's arXiv ID, with title, authors, arXiv link, and a one-paragraph summary.

## Selection criteria

The four starter papers were chosen by searching arXiv for work on tool use / function calling for LLM agents and ranking by relevance to the core topic, prioritizing:

1. Direct relevance to **tool use / function calling in LLM agents** (not just general agents or prompting).
2. **Canonical / influential** contributions (survey-scale or widely cited frameworks/benchmarks) that anchor the field.
3. **Complementary coverage** across surveys, frameworks/benchmarks, and training/tuning approaches, so the group sees the topic from multiple angles.

## How to use it

- Discuss papers in the child issues; cross-link related work as you find it.
- When a paper is done, close its child issue.
- Add new papers as new child issues under the parent, following the same format.
